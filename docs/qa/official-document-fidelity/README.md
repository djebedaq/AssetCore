# Проверка на вярността на официалните документи

Статус по време на разработката: **NOT READY**. Финалното становище, известните ограничения и изпълнените команди се записват в `release-readiness.md`. Архитектурният одит е записан преди промени в кода.

Доказателствата се генерират само от обозначени синтетични стойности, чрез действителните legacy и Studio DOCX renderers и същия Linux DOCX→PDF converter. Частните предоставени DOCX не се включват в repository, fixtures или CI artifacts. Нито един production ресурс не се използва.

Всяка комбинация от петте разновидности, BG/EN/RU и 1/5/30 реда има отделна подпапка с два DOCX, два PDF, PNG за всяка страница, side-by-side PNG и измерен JSON. При предаване/връщане броят checklist позиции идва от snapshot, а 1/5/30 е размерът на общия синтетичен вход; той не означава измисляне на 30 контролни позиции.

Възпроизводим генератор: `PYTHONPATH=backend:tests python tests/generate_official_fidelity_evidence.py` на изолиран Linux host с действителния приложен converter. `comparison-results.json` съдържа резултатите от цялата матрица. `preservation.json` пази списък и SHA-256 на защитените материали спрямо baseline.
