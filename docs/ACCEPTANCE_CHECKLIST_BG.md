# Проверка преди официално представяне

- [ ] Потвърдени са всички инвентарни и серийни номера.
- [ ] Логото и официалното наименование са одобрени.
- [ ] Реалните потребители и роли са уточнени.
- [ ] Паролите по подразбиране са сменени.
- [ ] PostgreSQL и автоматичният backup са активирани.
- [ ] Всички екрани са проверени на телефон и компютър.
- [ ] Генерираните Word/PDF документи са одобрени спрямо заводските образци.
- [ ] Проведен е демонстрационният сценарий без грешки.
- [ ] Одобрено е кои документи могат да се съхраняват в облака.
