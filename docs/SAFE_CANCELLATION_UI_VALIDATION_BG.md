# AssetCore v10 — проверка на интерфейса за безопасно анулиране

## Реализирано

- Бутон „Анулирай операцията“ се показва само за batch операции с незавършено подписване.
- Диалогът изисква причина от минимум 3 знака и показва различен ефект при издаване и приемане.
- При издаване машините се освобождават за нова операция.
- При приемане първоначалното активно издаване остава валидно.
- След успешно анулиране интерфейсът показва броя анулирани движения и обезсилени signing sessions.
- Списъкът с партиди, наличността и историята се презареждат след операцията.
- Поддържани са BG/EN/RU текстове и responsive изглед.

## Защити

- Не се изпраща заявка без валидна причина.
- Backend остава източникът на истина и отказва завършени или несъществуващи операции.
- Двойно натискане е блокирано по време на заявката.
- Грешките `batch_not_pending`, `batch_not_found` и `403` се показват локализирано.
