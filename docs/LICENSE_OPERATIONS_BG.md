# Операторски инструкции за лицензиране

1. Правоносителят генерира Ed25519 ключове извън repository и клиентската среда.
2. В инсталацията се задават само `INSTALLATION_ID` и `LICENSE_PUBLIC_KEY`.
3. Текущият собственик-administrator със завършен профил отваря „Настройки“ и
   избира подписания JSON envelope `{ "payload": ..., "signature": ... }`.
4. Проверете показаните client, licence ID, тип, срок, модули и лимити.
5. При грешен подпис, правоносител или installation ID API връща 409 и одитира
   отказа без частичен запис. Старият валиден лиценз остава активен.

За аварийна работа правоносителят може да издаде кратък
`EMERGENCY_TEMPORARY` лиценз със същия криптографски процес. Не изпращайте частен
ключ, password или environment файл на клиента.
