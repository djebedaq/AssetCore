# AssetCore v12.1 — live regression hotfix

Поправя установените след първия Render deploy проблеми:

- приемането на машини вече приема checklist payload без клиентски `label`;
- официалният протокол извежда каноничните локализирани наименования по `code`;
- ремонтната карта зарежда само потвърдени части за конкретната машина;
- позициите в каталога имат явен, keyboard-accessible избор и видима маркировка;
- стари ремонтни записи с несъответстващ машинен статус се синхронизират безопасно само в рамките на активния ремонт;
- добавянето на участник връща контролирана грешка вместо необработен database failure;
- миграция `20260805_0015` гарантира наличието на таблицата за участници.
