# Проверка на workflow за непозната част

## Реализирано

- Задължителна конкретна машина.
- Възел, описание, количество и незадължителна забележка.
- Задължителна JPEG/PNG/WebP снимка с проверка на файловия signature.
- Ясен статус „Част без потвърден part number“.
- Никакво автоматично добавяне в `part_catalog`.
- Защитено приложение, свързано с конкретния ред на заявката.
- Последващо административно свързване само към активна, VERIFIED и съвместима каталожна част.
- Оригиналното описание, снимката и audit историята остават непроменени.
