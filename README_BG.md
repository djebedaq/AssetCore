# AssetCore Director Edition v1.0 RC1

Професионална кандидат-версия за управление на HPWJ оборудване в „Одесос Кораборемонтен завод“.

## Какво съдържа
- React + TypeScript frontend.
- FastAPI backend.
- SQLite за локална проверка и PostgreSQL за продукционна среда.
- 19 HPWJ машини, без бояджийско оборудване.
- Регистър, местоположение, статуси и QR кодове.
- Приемо-предавателни операции и генериране на Word/PDF.
- Ремонти, диагностика, извършена работа и тестване.
- Заявки за резервни части.
- Проверен каталог на CombiJet части с Part No. и източник.
- Пълна библиотека с предоставените Falch, HYDWIN/Fussen и CombiJet документи.
- 14 реални HPWJ ремонтни протокола и 13 реални HPWJ заявки като референтна база.
- Журнал на действията, табло и справки.
- Docker, Render и GitHub Actions конфигурация.

## Бърз старт с Docker
1. Инсталирай Docker Desktop.
2. Разархивирай проекта.
3. В папката изпълни:
   `docker compose up --build`
4. Отвори: `http://localhost:10000`
5. Вход за локална демонстрация:
   - Email: `admin@assetcore.local`
   - Парола: `AssetCore123!`

Преди реално внедряване смени паролата и `SECRET_KEY`.

## Offline проверка на backend
От главната папка:
`python verify_release.py`

## Важно за официалното представяне
Това е Release Candidate. Програмната основа и документалната библиотека са готови за директорска демонстрация. Преди официално внедряване трябва да се подпишат финално: точните полета и визуалното оформление на генерираните протоколи, потребителските роли, облачното съхранение и политиката за резервни копия.
